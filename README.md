# D3D12 Renderer

Direct3D 12(D3D12)로 처음부터 직접 만드는 렌더러입니다. GPU에 그리기 명령을 보내고 화면에 프레임을 표시하기까지 어떤 일이 일어나는지 코드로 익히는 프로젝트입니다.

## 개발 방식

AI 바이브 코딩 없이 렌더러의 설계, 구현, 디버깅을 직접 합니다. Direct3D 12 공식 문서와 예제를 참고하며, GPU 리소스의 상태를 언제 전환해야 하는지, CPU와 GPU를 어디서 동기화해야 하는지 직접 구현하고 확인합니다.

## 참고 출처

Direct3D 12 API 사용법과 구현 예제를 살펴보기 위해 Microsoft의 공식 샘플 코드를 참고했습니다. [Microsoft DirectX Graphics Samples](https://github.com/microsoft/DirectX-Graphics-Samples)

렌더러 구현을 시작하기 위한 저장소를 준비한 단계입니다.
